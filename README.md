# SlideShooter

A simple vertical space shooter, developed with GDScript and the Godot engine. I was testing this scripting language and learning how to make games.

**Play it in your browser (works on phones too): https://stevkazt.github.io/SlideShooter/**

Slide a finger to move the ship; it shoots on its own. The game was first made for Android in 2020 with Godot 3 and later ported to Godot 4; the web version is a Godot 4.3 export built into `docs/`.
